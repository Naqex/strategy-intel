Overview

ICT FULL SUITE is an advanced trading indicator built for MetaTrader 5 (MT5), designed to fully automate Smart Money Concepts (SMC) and Inner Circle Trader (ICT) frameworks. This premium software serves as an institutional market map for high-volume assets including Forex (EURUSD, GBPUSD), Gold (XAUUSD), and Crypto across key execution timeframes (M5, M15, H1, H4). By stripping away manual charting, it delivers data-driven liquidity setups straight to your screen.

🔎 How Does ICT FULL SUITE Work?

The core engine maps institutional price delivery via the Interbank Price Delivery Algorithm (IPDA). Price is programmed to chase liquidity and rebalance inefficiencies using the Power of 3 (PO3) cycle:

  • Accumulation: Controlled range during the Asian Session to build up liquidity pools on both sides.
  • Manipulation: A false breakout at London/NY open (Judas Swing) designed to trigger retail stop-losses.
  • Distribution: High-momentum expansion (Displacement) toward the real daily trend direction.

The indicator auto-syncs with New York Time (including DST adjustments) to plot algorithmic Killzones. The moment a candle closes, it locks in market structure shifts (BOS and MSS/CHoCH).

To filter out low-probability entries, the software runs a live ICT Score (0–100) matrix and a Premium / Discount engine. This ensures you execute sniper entries: Buy only in Discount zones (ICT Score ≥ 60) and Sell only in Premium zones (ICT Score ≤ 40).

📋 Key Features of ICT FULL SUITE

  • Algorithmic Killzones: Auto-plots precise trading windows for Asian Range, London Open, NY AM, London Close, and NY PM sessions.
  • Liquidity Tracking: Live-maps institutional target levels including Previous Daily High/Low (PDH/PDL), Weekly High/Low (PWH/PWL), and Equal Highs/Lows (EQH/EQL).
  • Institutional PD Arrays: Institutional volume blocks (+OB / -OB) and Fair Value Gaps (+FVG / -FVG) are mapped instantly using custom ATR momentum filters.
  • Mitigation Clean-up: Automatically dims or hides used-up zones (HideFilled) to maintain an ultra-clean, clutter-free desktop interface.
  • Telegram Alerts: Features zero-latency execution signals pushed directly to your phone via Windows native wininet.dll script integrations.

⚙️ How to Install and Setup ICT FULL SUITE on MT5

Follow this step-by-step technical blueprint to deploy the indicator on your MetaTrader 5 platform in less than 5 minutes:

Step 1: Add the Indicator Files to MT5

  • Open your MetaTrader 5 terminal.
  • Click on File in the top menu and select Open Data Folder.
  • Navigate to MQL5 inside Indicators.
  • Copy and paste the downloaded ICT FULL SUITE v1.12.ex5 file into this folder.

Step 2: Enable WebRequest for Telegram Alerts (Optional)

If you want real-time trading signals pushed straight to your phone, you must allow MT5 to communicate with Telegram:

  • In MT5, go to Tools inside Options (or press Ctrl + O).
  • Click on the Expert Advisors tab.
  • Check the box: "Allow WebRequest for listed URL:".
  • Double-click the green "+" icon and add this exact URL: https://telegram.org.
  • Click OK to save.

Step 3: Load the Indicator to Your Chart

  • Refresh your Navigator window in MT5 (or press Ctrl + N).
  • Expand the Indicators tree and find ICT FULL SUITE v1.12.
  • Drag and drop the indicator onto your target chart (e.g., EURUSD, GBPUSD, or XAUUSD).
  • In the pop-up window, go to the Common tab and check "Allow DLL imports" (This is mandatory for the system to process timezone and Telegram algorithms smoothly).

Step 4: Configure Key Parameter Inputs

Before hitting start, adjust these 3 critical parameters in the Inputs tab to lock in your strategy:

  • Timezone Settings: The indicator auto-syncs with New York time. Ensure your chart's history is fully loaded to let the algorithm calibrate Daylight Saving Time (DST) automatically.
  • Liquidity Sensitivity (EqTolATR): Set this parameter to define how strict the algorithm should be when detecting Equal Highs/Lows (EQH/EQL).

Momentum Threshold (DispATR): Adjust this to filter out weak market moves, ensuring the system only draws Order Blocks (OB) and Fair Value Gaps (FVG) created by true institutional volume.
