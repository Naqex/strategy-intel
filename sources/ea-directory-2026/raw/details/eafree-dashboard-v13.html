Overview

Welcome to our detailed review of EAFree Dashboard Version 1.3. This is currently one of the most powerful tools for MT5 account statistics. To be clear right away: this is not an auto-trading robot (No-trading EA). Instead, it is an optimal Forex capital management assistant dedicated to data analysis and aggregation. You can apply this EA to ALL currency pairs or trading assets, and on ALL timeframes of MetaTrader 5. By transforming dry numbers into an intuitive visual interface, EAFree Dashboard helps you control risks and accurately evaluate the performance of every running trading system.

How Does EAFree Dashboard V1.3 Work?

EAFree Dashboard V1.3 operates by scanning and extracting the entire MT5 account history. Instead of displaying a chaotic list of orders, the EA groups the data by their unique identifiers (Magic numbers). As a result, a neat and organized performance statistics board is created.

Regarding its operational logic, this tool automatically classifies the status of each strategy. The "Running" status is assigned if there are open orders or recent transactions within the InpRunningDays parameter. If there is no recent activity, the status switches to "Paused". If there are absolutely no orders during the period, it is marked as "Stopped".

Despite being a No-trading EA, it still provides a highly valuable interaction mechanism. You can close all active orders of a specific strategy with just a single click on the dashboard. For this feature to work, you simply need to enable "Allow Algo Trading" in the initial settings.

Key Features of EAFree Dashboard V1.3

This tool delivers a comprehensive analytical ecosystem with the following outstanding technical features:

💠Flexible Magic Declaration: Supports assigning specific names or numerical ranges (from-to). It also automatically recognizes manual trades via Magic 0.

💠Overview Tab & KPI Cards: Provides the big picture with core metrics. You can track Total Profit, Win Rate, Profit Factor, and Drawdown. Additionally, the EA calculates advanced ratios like Sharpe, Sortino, and Calmar.

💠Visual Charting Tools: Integrates a trading day Heatmap to quickly spot bad days. A Pearson Correlation matrix allows cross-comparison of up to 12 strategies to prevent risk duplication. Profit distribution charts and best trading hours are also clearly presented.

💠Advanced Supplementary Tabs: The Performance tab offers a summary table of 28 advanced analytical metrics. The Trades tab displays a detailed order history filtered by strategy. The Risk tab supports managing risk to the Stop-Loss (SL) point and red-flags orders without an SL. Finally, the Calendar tab visualizes monthly trading results on a grid.

 

How to Install and Configure EAFree Dashboard V1.3

For this MT5 account statistics tool to operate accurately and maximize its efficiency, you need to follow the detailed installation and configuration steps below:

1. Basic Installation on MetaTrader 5

  • Step 1: Copy the EAFree_Dashboard_V1.3.mq5 file into the MQL5/Experts folder (You can open this folder by selecting File → Open Data Folder in MT5).
  • Step 2: Open MetaEditor, locate the copied file, and press the F7 key to compile the system.
  • Step 3: Open any price chart (preferably a non-trading chart) and drag and drop the EA onto it. The price chart will immediately be hidden and replaced by the Dashboard panel.

2. Granting Operating Permissions (Crucial)

When the settings dialog opens, under the Common tab, you need to pay attention to the following two options:

  • Check Allow DLL imports: Mandatory to activate the links that open the website and Telegram channel directly in your browser.
  • Check Allow Algo Trading: Only enable this feature if you want to use the automated close-trade button (Close-by-strategy) integrated into the dashboard.

3. Configuring Strategy Identifiers (InpMagicMap) By nature, MT5 only saves the Magic Numbers of trades, not the names. For the statistics board to display clearly, you need to declare the names in the Inputs tab using the InpMagicMap parameter.

  • Standard syntax: magic Name; or a number range from-to=Name; (strategies are separated by semicolons).
  • Practical example: 1001 Gold Scalper; 8000-8999 Strategy Pool; 0 Manual Trades. (Note: Magic 0 is always used to identify manual trades).

4. Customizing the Display Interface If strategy names or numbers overlap or overflow due to a small screen, you simply need to decrease the InpFontSize (Font size) parameter by 1-2 units. The entire layout of the dashboard will automatically scale in sync with the new font size to fit perfectly on your screen.

Performance & Statistics Results

Based on accurate statistical evidence, this tool helps traders clearly distinguish between genuinely effective systems and unstable ones. The performance metrics are calculated transparently and reflect reality closely.

Net profit is measured accurately, including gross profit/loss, overnight fees (swap), and commissions. The dashboard places special emphasis on the Recovery factor; a level above 3 indicates a very robust system. Similarly, a Return/Drawdown ratio (Return/DD) greater than 3 proves the system is solid enough for a real account.

However, to ensure data accuracy, users must note a crucial rule from the manual. You should absolutely not draw performance conclusions if the data sample has fewer than 100 orders and fewer than 20 trading days. Statistical ratios will experience heavy noise when the sample size is too small.

Weaknesses and Risk Warnings

To ensure transparency according to financial software evaluation standards, we must clearly outline the limitations and risks when using this tool:

💠The Equity line on the main chart is plotted using only CLOSED orders. Floating drawdowns during the day when orders are running will not appear on this line. The current equity level is merely represented by a standalone blue dot.

💠The currency display conversion feature (InpCurrencyRate parameter) relies on a fixed exchange rate manually entered by the user. The system will not automatically update cross rates according to the real-time market.

💠Risk Warning: All statistical data extracted from the dashboard is for reference purposes only, based on historical trading. It is absolutely not investment advice and does not guarantee future profitable results. You are solely responsible for managing your account risks. In particular, exercise extreme caution with open trading orders that do not have a Stop-loss set.
